# Dark KittyBorn

Затишно-готична гра для Android-планшета і браузера. Кошеня-Ліхтарник рубає дрова, наймає Профспілку Котів, будує лісопилку, склад і вежі, а вночі захищає ліхтарі від Пухнастих.

Стек: Phaser 4 + TypeScript + Vite, Android через Capacitor 8, тести на Vitest. Лор, сюжет і геймдизайн лежать у `../drovoborn/docs/`.

## Структура

- `src/content/data.ts`: увесь контент як дані (предмети, будівлі й рівні, майданчики, апгрейди, хвилі).
- `src/sim/`: симуляція без графіки (світ, фізика, економіка, логістика котиків, ночі, збереження). Її можна тестувати без браузера.
- `src/render/`: Phaser-сцена; процедурний арт малюється один раз у текстури.
- `src/ui/hud.ts`: HTML-інтерфейс (HUD, картки будівель, підказки, джойстик, меню).
- `src/platform/`: звук і збереження.
- `tests/`: тести симуляції.

## Команди

```
npm install
npm run dev            # локально в браузері
npm test               # тести симуляції
npm run build          # dist/ для Capacitor і вебу
npm run build:single   # dist-single/index.html — один офлайн-файл
npx cap sync android && (cd android && ./gradlew assembleDebug)   # APK (потрібні JDK 21 і Android SDK)
```

GitHub Actions (`.github/workflows/kittyborn.yml`) на кожен push у `kittyborn/` проганяє тести і кладе `release/DarkKittyBorn.apk` і `release/DarkKittyBorn-offline.html` у гілку.

## Логістика котиків

Будівлі й майданчики публікують потреби, склад і лісопилка є джерелами. Вільний котик оцінює всі можливі рейси (`listTrips`) і бере найкращий. Кількість резервується і в джерелі, і в місці доставки, тож два котики не женуться за тим самим вантажем, а рейс не скасовується через кожну нову річ. Дрібні рейси відсікаються порогом партії.
