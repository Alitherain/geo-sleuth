# Дровоборн

Мило-готична ідл-гра для Android-планшета: рубаєш дрова, здаєш їх у лавку Пані Сови, наймаєш котиків-помічників, будуєш лісопилку й коптильню, полюєш на пухнастих звірят і зрештою кличеш Пана Пухнастого, Жаха Блідого Місяця.

- `index.html` — уся гра (canvas, без залежностей; шрифти з Google Fonts, якщо є інтернет).
- `android/` — обгортка WebView. `android/build-apk.sh` збирає `Drovoborn.apk` (потрібні JDK 17, Gradle 8.9 і Android SDK 34).
- GitHub Actions (`.github/workflows/drovoborn-apk.yml`) збирає APK на кожен push у `drovoborn/` і кладе його в артефакт `Drovoborn-apk`.

Керування: торкнись будь-де й веди пальцем (плаваючий джойстик). Рубання, бій і передача ресурсів відбуваються самі, коли стоїш поруч або на майданчику. Кнопка «Назад» відкриває паузу.
